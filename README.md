NEON VOID — a neon twin-stick arena shooter that runs offline in a desktop browser from
static files. Move with WASD or the arrow keys, aim with the mouse, hold click or Space to
fire. Waves of chasers, shooters, splitters and brutes close in with escalating difficulty,
and a boss — the Void Warden — arrives every 5 waves with radial bursts, aimed spreads
and a spiral barrage. Clear a wave to pick one of three upgrades (spread shot, rapid fire,
piercing rounds, hull plating, aegis shield, tractor magnet, nova bomb and more), chain
kills into a combo multiplier, and chase the best score. All art is vector neon drawn in
code and all sound is synthesised with the Web Audio API — no assets, no network requests,
no libraries.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
